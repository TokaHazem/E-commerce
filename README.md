# 🛒 Custom PHP MVC E-Commerce System

A dynamic, flexible, and robust E-Commerce platform built from scratch using object-oriented **PHP (MVC Architecture)** and **MySQL**. This project demonstrates core e-commerce functionalities from user browsing to cart management and checkout logic.

## ✨ Core Features
- **User Authentication:** Secure signup, login, and session management for customers.
- **Product Catalog:** Dynamic rendering of products categorized efficiently with detailed views.
- **Shopping Cart System:** Fully functional cart allowing users to add, update quantities, and remove items seamlessly.
- **Secure Checkout Logic:** Structured backend flow to process orders and handle cart data.
- **MVC Architecture:** Built with separation of concerns (Models, Views, Controllers) for scalable and maintainable clean code.

## 🛠️ Tech Stack
- **Backend:** PHP (OOP, MVC Pattern)
- **Database:** MySQL (Relational database design)
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap for responsive design

## 📸 Project Architecture Preview
The system routes requests through a unified Front Controller, ensuring secure routing and clean URLs across the store.
